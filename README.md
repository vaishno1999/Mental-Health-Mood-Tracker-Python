# 🧠 Mental Health Mood Tracker

## 📌 Project Overview

**Mental Health Mood Tracker** is a simple Python-based project that allows users to record their daily moods and receive motivational messages based on their selected emotions.

The project also provides a weekly summary of the moods entered by the user.

## 🎯 Objectives

* Track daily moods.
* Provide motivational messages based on emotions.
* Maintain a simple mood log.
* Display a weekly mood summary.
* Encourage regular emotional self-check-ins.

## 🛠️ Technologies Used

* Python
* Lists
* Dictionaries
* Loops
* Conditional Statements
* String Methods

## 😊 Moods Supported

* Happy
* Sad
* Angry
* Anxious
* Tired
* Neutral

## ⚙️ Features

* Daily mood input
* Motivational message for each mood
* Mood validation
* Mood history
* Weekly mood summary
* Simple command-line interface

## 🔄 How It Works

1. Start the program.
2. Enter your mood for each day.
3. The program displays a motivational message.
4. The mood is stored in the mood log.
5. Continue entering moods or type `done`.
6. The program displays the weekly mood summary.

## 📊 Example

```text
Welcome to the Mental Health Mood Tracker

Enter your mood for Day 1: happy
Quote: Keep smiling! Happiness is contagious

Enter your mood for Day 2: anxious
Quote: You're doing the best you can. One step at a time

Enter your mood for Day 3: sad
Quote: It's okay to feel sad. Better days are coming

Weekly Mood Summary:
Day 1: Mood - Happy
Day 2: Mood - Anxious
Day 3: Mood - Sad
```
